# AI-Assisted Horror Game - Aippy Platform
A horror-themed survival game designed and developed through iterative AI prompting and extensive manual customization. The player races against time through a dense forest, avoiding trees and monsters while navigating toward a cabin as the finish line.
What makes this different:
Unlike typical AI-generated platform outputs, this project involved sustained creative direction and technical refinement across every element of the game. The AI provided a starting framework that was then extensively rebuilt through specific prompt engineering and hands-on customization.
Audio design:
Custom sound design was a central focus - footstep effects and a physical bounce were added to simulate running through the forest, with both elements dynamically synced to player speed in real time. Audio assets were designed specifically for the game's environment and pacing rather than using any default platform sounds.
Technical customization:

Steering sensitivity, speed, and acceleration tuned through iterative prompting
Lighting, landscape, and forest density dialed in to support the horror atmosphere
Native AI-generated elements selectively removed where they conflicted with the intended design
Monster behavior and cabin finish line integrated into the core game loop

Tools: Aippy generative AI platform, custom prompt engineering, original sound design
